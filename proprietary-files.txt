# pdx256 리커버리 복호화용 blob -- native 변형
#
# 이 브랜치(native-blobs)는 pdx256 자신의 vendor blob 을 씁니다.
# master 의 pineapple(SM8650) 세트와 비교하기 위한 것입니다.
#
# 진짜 병목은 blob 이 아니라 /dev/smcinvoke 권한이었습니다 (master 참고).
# 그 수정이 들어간 뒤에는 양쪽 다 TZ 핸드셰이크가 가능해야 합니다.
# native 쪽이 아키텍처상 더 맞습니다 -- 이 기기의 TZ 앱과 같은 세대라
# wrappedkey_v0 키 처리에서 어긋날 여지가 적습니다.
#
# 위치가 /system 이 아니라 /vendor 인 이유:
# native 세트에는 vendor 버전 libc++(1083168, __libcpp_verbose_abort 보유),
# libbase, libcrypto, libhidlbase 등이 포함됩니다. 이걸 /system/lib64 에 두면
# Android 14 로 빌드된 TWRP 자체 바이너리를 깨뜨립니다. /vendor/lib64 에 두면
# rc 의 LD_LIBRARY_PATH(/vendor/lib64 우선)가 vendor 프로세스에만 적용됩니다.
#
# gatekeeper 도 다릅니다: pineapple 은 HIDL @1.0, pdx256 은 AIDL 입니다.
