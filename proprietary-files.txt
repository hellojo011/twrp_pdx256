# pdx256 — TWRP /data 복호화용 vendor blob 목록
#
# 이 목록은 추측이 아니라 super.sin 에서 vendor_a 를 뽑아
# keymint HAL 바이너리의 DT_NEEDED 를 재귀적으로 따라가 만든 폐포(closure)입니다.
# libc/libdl/liblog/libm/libbinder_ndk/libvndksupport 는 TWRP 램디스크에 이미 있으므로 제외.
#
# 확인된 사실:
#   - vintf 에 선언된 기본 HAL 은 android.hardware.security.keymint v3 IKeyMintDevice/default
#     -> /vendor/bin/hw/android.hardware.security.keymint-service-qti  (TEE/TZ 경로)
#   - SPU 쪽(keymint-service-spu-qti)은 vintf 선언이 없는 StrongBox 인스턴스라 불필요
#   - keymint 는 qseecomd 가 먼저 떠 있어야 동작 (TA 로드)
#   - TA 이미지는 vendor 안이 아니라 modem 파티션에 있고
#     /vendor/firmware_mnt 로 마운트됩니다 -> recovery.fstab 항목 필수

# --- TZ 리스너 서비스 (qseecomd 가 dlopen) -----------------------------
# qseecomd 는 이 라이브러리들을 dlopen 으로 로드합니다. DT_NEEDED 에 없으므로
# 정적 의존성 분석으로는 잡히지 않고, 하나라도 빠지면 리스너 등록 전체가
# 실패하면서 qseecomd 가 255 로 종료합니다:
#   ListenerMngr: Init dlopen(librpmb.so, RLTD_NOW) is failed....
#   QSEECOMD: ERROR: Failed to start listener services.
# 리스너가 없으면 keymaster TA 가 콜백을 못 해 keymint 가 등록되지 못하고,
# keystore2 는 NAME_NOT_FOUND 로 panic 합니다.
